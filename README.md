# Mais Livros-Livraria

Criado como forma de teste, a Mais Livros é uma empresa fictia, de vendas de livros online.
De inicio a ideia é utilizar do Next.js, Node.js, typescript e do tailwind para criação desse site.
Será simples contendo apenas poucas páginas contando com os objetivos que é um Header, Hero, Footer e um tca.
